{% comment %} Image carousel. Include it as many times as you like in one article. The slides come from the first of these that is set: - include.images (a list, OR a string for inline declaration) - include.name (looks up page.carousels[name]) - page.carousel (legacy single-carousel front matter) When include.images is a string it is split on newlines (if it has any) or on commas. Each entry is `src`, `src | caption`, or `src | caption | alt`. Array items may be either: - a plain string image path/URL - a map with `src` (required), and optional `caption` and `alt` Paths that are not absolute (/...) or full URLs (http...) are resolved against `page.contentDir`, matching the rest of the blog's images.
